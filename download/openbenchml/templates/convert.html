📚 How /convert works

Three steps. Basic syntax, powerful engine.

The 3 steps

  1. You write Python that trains a model and assigns it to model.
  2. OpenBenchML executes your code in a sandboxed namespace — np, pd, sklearn are pre-imported.
  3. The model is pickled and saved as an MLModel. You can benchmark it instantly.

What's pre-imported

These names are available in your code with no import needed:

  • np  → numpy
  • pd  → pandas
  • sklearn  → scikit-learn
  • scipy  → scipy
  • joblib  → joblib
  • sklearn_datasets
  • sklearn_linear_model
  • sklearn_ensemble
  • sklearn_svm
  • sklearn_neighbors
  • sklearn_neural_network
  • sklearn_tree
  • sklearn_metrics
  • sklearn_model_selection
  • sklearn_preprocessing
  • sklearn_pipeline
  • sklearn_decomposition

Security

For your safety, the sandbox blocks:

  • open(), file I/O
  • os.system, subprocess
  • socket, http, urllib
  • ctypes, shutil

Execution has a 60-second timeout.
