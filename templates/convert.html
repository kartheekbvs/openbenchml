📚 How /convert works

Three steps. Two engines. Pick whichever fits your training budget.

The 3 steps

  1. You write Python that trains a model and assigns it to model.
  2. OpenBenchML executes your code — either in your browser (Pyodide, no timeout) or in the server sandbox (300s limit). np, pd, sklearn are pre-imported.
  3. The model is pickled and saved as an MLModel. You can benchmark it instantly.

Which engine should I pick?

Pyodide (recommended) — trains in your browser using WebAssembly. No server timeout. The browser tab can run as long as your model needs (RandomForest on California Housing, XGBoost with 500 trees, etc.). First load downloads ~30 MB of packages; subsequent runs are instant.

Server sandbox — runs on the server. Useful if your browser is slow or you want to close the tab. Hard 300-second limit (5 min). Best for small/medium models only.

Security

For your safety, the server sandbox blocks:

  • open(), file I/O
  • os.system, subprocess
  • socket, http, urllib
  • ctypes, shutil

Pyodide runs in your browser's sandbox — no server access at all.
