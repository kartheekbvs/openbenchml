Architecture at a glance

Three layers, each doing one job. Click any workflow below to see how data flows through them.

Browser
Jinja2-rendered HTML + vanilla JS + fetch(). xterm.js for the terminal. WebSocket client for live updates.
FastAPI server
Async route handlers, Pydantic validation, per-user kernel sessions, WebSocket broadcast, sandboxed shell executor.
Database + files
SQLAlchemy ORM → SQLite (dev) / Supabase Postgres (prod). Pickled models live on disk under uploads/.
